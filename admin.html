Cómo interpretar estos datos

La medición empieza al publicar los cambios

No podremos reconstruir visitas anteriores que no se registraron. El conteo se basa en eventos enviados por el navegador y puede excluir usuarios que bloqueen JavaScript o las solicitudes.

Este módulo guarda hora de visita, ruta pública, un identificador aleatorio del navegador y el dominio de referencia. No guarda nombres, correos ni direcciones IP en la tabla de analítica. Antes de utilizarlo en producción, incorpora esta medición a la política de privacidad del sitio.
Para activar las estadísticas, ejecuta el archivo site_analytics.sql en el SQL Editor de Supabase y publica las versiones actualizadas de index.html y admin.html.
